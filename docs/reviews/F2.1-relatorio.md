# F2.1 — Lista de peças do Hangar (catálogo, entidade, banco e provisionamento)

**Branch:** feat/parts-f2.1 · **Commits:** fcfbd8f (feat), b257453 (test) · **Data:** 2026-11-15 (Rodada 2)

## Correções da Rodada 2 (Revisão do Claude)

Em resposta à revisão de veredito **CORRIGIR** (`docs/reviews/F2.1-revisao.md`), foram implementados rigorosamente os 5 itens:

1. **Peças por motor (`PerEngine`) e índice de motor (`EngineIndex`)**:
   - `PartDefinition`: adicionada a propriedade `public bool PerEngine { get; init; } = false;` (aplicada a motor, óleo, ignição, seção quente, hélice, alternador, starter-generator, bomba mecânica do motor, FCU, turbo, partida).
   - `AircraftPart`: adicionada a coluna `public int EngineIndex { get; set; } = 0;` (1..N para peças por motor; 0 para peças gerais da célula).
   - `AppDbContext`: índice único atualizado para `(PilotAircraftId, PartId, EngineIndex)`. Em `EnsureSchemaUpdatedAsync`, script idempotente adiciona a coluna `EngineIndex` e recria o índice único.
   - Contagem de motores (`engineCount`): adicionado o campo `engineCount` nos 46 arquivos `Data/aircraft/*.json` (4 para 747-8i, 747-400, A400M e ES-30; 2 para demais multimotores; 1 para monomotores), validado pelo `_schema.json`, carregado por `AircraftLimitCatalogLoader`, persistido em coluna nova `EngineCount` de `AircraftLimitProfiles` via `AircraftLimitSeeder`.
   - `AircraftPartProvisioner`: para peças `PerEngine`, gera N instâncias com `EngineIndex` de 1 a N. Para peças de célula/gerais, gera 1 instância com `EngineIndex = 0`. Idempotente e preserva peças existentes.

2. **Segregação rigorosa de peças de pistão vs turbina**:
   - As peças `oil.lubricant`, `oil.filter`, `oil.pump`, `fuel.engine_pump`, `fuel.filter_gascolator`, `electrical.alternator` e `engine.starter` foram restritas a `all: [piston]`.
   - Criadas versões dedicadas para turbinas (jato e turboélice) com vidas úteis e fontes adequadas: `oil.turbine_oil` (800 h), `oil.turbine_filter` (600 h) e `oil.turbine_pump` (3.500 h).

3. **Peças centrais de turbina adicionadas**:
   - Adicionadas:
     - `engine.compressor` (compressor axial/centrífugo, turboélice e jato, 3.500 h, por motor).
     - `engine.reduction_gearbox` (caixa de redução RGB, exclusivo turboélice, 3.500 h, por motor).
     - `electrical.starter_generator` (partida-gerador de turbinas, no lugar de alternador/starter, 2.500 h, por motor).
     - `fuel.fcu` (unidade de controle de combustível FCU/HMU, turboélice e jato, 3.500 h, por motor).
     - `engine.fan` (fan frontal de turbofan, exclusivo jato, 4.000 h / 3.000 ciclos, por motor).
     - `engine.thrust_reverser` (reversor de empuxo, exclusivo jato, 3.000 h / 2.500 ciclos, por motor).

4. **Padronização de fontes (`LifeSource`)**:
   - Seguindo a regra da casa para dados sem documento aberto nesta tarefa: todas as peças sem manual aberto foram padronizadas como `"estimativa — revisar (referência usual: <referência>)"`.

5. **Preço de referência e flag de escala (`priceScalesWithAircraft`)**:
   - Adicionada a propriedade `public bool PriceScalesWithAircraft { get; init; } = false;` em `PartDefinition` e em `parts_catalog.json`.
   - O campo `PartPrice` representa o preço base de referência para a aviação geral leve (GA). Para peças estruturais, motores, aviônicos de grande porte e atuadores complexos, `priceScalesWithAircraft: true` sinaliza ao Hangar da F2.3 que o custo deve escalar proporcionalmente ao valor de mercado da aeronave.
